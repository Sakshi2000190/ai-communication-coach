# AI Communication Coach

## About the Project

AI Communication Coach is an AI-powered web application designed to help students improve their communication skills, speaking confidence, and interview performance.

The application provides two main practice modes: Interview Practice and Random Topic Practice. Users can enter their responses or use speech-related features to practice. The system analyzes responses and provides feedback and suggestions for improvement using AI technology.

## Features
- Interview preparation and practice
- Random topic speaking practice
- Speech and text input
- AI-based response analysis and feedback
- Practice dashboard and statistics

## Technologies Used
- React and TypeScript
- Node.js and Express.js
- Google Gemini API
- Supabase
- Vite

## Objective

The main objective of this project is to provide students with an accessible platform to practice communication skills, prepare for interviews, identify areas for improvement, and build confidence.
